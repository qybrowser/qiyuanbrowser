# HTTP 接口分层

`server.py` 负责创建管理应用、初始化浏览器资源并挂载两个路由模块：

- `server_api.py`：环境与代理的服务端增删改查、指纹拉取、错误与标签上报、首页/错误页数据、浏览器状态。
- `local_api.py`：本机浏览器控制、设置、检测、管理 UI 与页面兼容接口。

浏览器应用数据目录中的 `config/config.json` 会在客户端启动时生成。三个地址各有用途：`base_api_path` 是服务端接口，`base_local_api_path` 是本地客户端接口，`browser_base_path` 是首页和错误页地址。默认三者可指向同一个管理进程；若分别部署，服务端和本地客户端通过 `base_api_path` 共享环境数据。

原 URL 和响应结构在本次路由拆分中保持不变。
